- English prose (SPEC.md §5 — everything in the repository in English). Polish product
  copy is quoted verbatim as content, with an English gloss where useful.

  (`status: refining`) and ends as a one-pager with an MVP scope and a "Not doing"
  list (`status: refined`). Superseded memos get `status: retired` and a pointer.

  the issue remains the place where a decision becomes binding.
